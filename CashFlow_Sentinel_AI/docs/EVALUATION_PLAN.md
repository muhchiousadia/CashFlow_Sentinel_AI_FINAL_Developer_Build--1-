# Independent Evaluation Plan — v0.8

## Automated checks performed on this build
- Unit and regression tests cover cashflow, scenarios, data validation, network propagation, financing comparison, evidence grounding, authentication/password hashing, role checks, persistent audit logging, and forecast-versus-actual metric calculation.
- Run `python -m pytest -q`; record the exact output generated by the submitted code.
- Run `python scripts/run_demo_evidence.py` to recreate deterministic synthetic evidence. Synthetic evidence is not real-world validation.

## Real-data validation workflow
The developer cannot claim real SME validation without permissioned, independently reconciled outcomes. Obtain authorization, remove unnecessary personal identifiers, confirm one currency and timezone, and prepare:
- `transactions.csv`: documented transaction schema described in README.
- `actual_daily_cash.csv`: `date,actual_closing_cash` from independently reconciled books/bank statements.

Run from the source_code folder:
`python scripts/evaluate_real_data.py transactions.csv actual_daily_cash.csv BUSINESS_ID OPENING_CASH YYYY-MM-DD`

The tool writes matched forecast-vs-actual rows, MAE, RMSE and bias. Review missing dates, data leakage, reconciliation quality, currency and horizon. Do not claim accuracy based on synthetic data. Use a chronological holdout and multiple SMEs before generalizing.

## Recommendation evaluation
For each test case, a reviewer should independently calculate the expected answer and verify that every displayed evidence row maps to source records, the recommendation follows stated rules, uncertainty is visible, and the model does not invent values. `src/independent_eval.py` includes a traceability check helper. LLM outputs require separate blinded human review; deterministic unit tests do not prove semantic correctness.

## Reporting
Report dataset provenance, permission status, time range, sample size, missingness, reconciliation method, metric definitions, baselines, failures and limitations. Do not publish private SME data.
